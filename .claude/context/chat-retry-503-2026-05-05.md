# Summary
Added retry resilience in the /chat route to reduce transient 503 errors when Ollama returns temporary 5xx during model load.

# Files created/modified
- config.py: added CHAT_RETRY_ATTEMPTS and CHAT_RETRY_BACKOFF_SECONDS env settings.
- routes/chat.py: introduced _ollama_chat_with_retry and routed all /chat-stage ollama_chat calls through it.
- tests/test_routes.py: added test_chat_retries_transient_http_500 covering one failed attempt followed by success.

# Decisions made
- Retry only retryable failures (HTTP 500/502/503/504 and request errors).
- Keep external API contract unchanged: /chat still returns 503 when all attempts fail.
- Reuse the same retry wrapper in optional context-gate passes for consistent behavior.
